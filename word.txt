第一章 项目概述
1.1 项目背景
本项目"智绘城乡·焕新家"是一个基于AI技术的家居设计平台，旨在通过AI技术赋能家居产业链，降低设计门槛，提升供需效率。

1.2 技术架构
1.2.1 前端架构
- 核心框架：Vue 3 + Vite
- 状态管理：Pinia
- UI组件库：Vant UI
- 路由管理：Vue Router
- 动画效果：CSS3 + SVG
- 响应式设计：Flexbox + Grid

1.2.2 后端架构
- 服务框架：Flask
- API网关：Nginx
- 数据库：MongoDB
- 缓存系统：Redis
- 文件存储：MinIO

1.2.3 AI服务架构
- 模型服务：混元API + OpenAI API
- 图像处理：OpenCV
- 文本处理：NLP模型

第二章 核心功能模块
2.1 AI智能设计模块
2.1.1 提示词优化
- 接口：/api/polish
- 功能：优化用户输入的提示词
- 实现：基于混元API的文本优化
- 特点：
  - 支持1000字符以内的提示词
  - 提供专业、详细和富有创意的优化建议
  - 保持原有核心意思，添加更多细节

2.1.2 AI评价功能
- 接口：/api/openai_review
- 功能：对上传的家居图片进行AI评价
- 实现：基于OpenAI API的图像分析
- 特点：
  - 支持多种图片格式
  - 提供专业的设计建议
  - 自动识别设计风格和问题

2.2 电商服务模块
2.2.1 商品管理
- 功能：
  - 商品列表展示
  - 商品详情页
  - 商品搜索
  - 商品分类
- 实现：
  - 使用Vue组件实现商品展示
  - 支持响应式布局
  - 集成图片懒加载

2.2.2 购物车系统
- 功能：
  - 添加商品
  - 修改数量
  - 删除商品
  - 计算总价
- 实现：
  - 使用Pinia进行状态管理
  - 本地存储持久化
  - 实时价格计算

2.3 用户系统
2.3.1 用户认证

  - 用户登录

2.3.2 个人中心
